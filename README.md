# Fedora Script

This script will help to provide in seconds a good dev or everyday usage for Fedora Linux.

# What it delete, mask or desactive

This script will delete all unnecessary packages (look at the script if there's some packages you want to keep).
It will remove the Wait Online system-d program because it causes boot to be slower and things like gnome parental control at startup.

# Advices for after the script

If the script succed, my advice would be to do a custom kernel configuration, that will remove unnecessary drivers or other GPU supports you on't need...

# Disclaimer

This script, is focused on the Fedora GNOME workstation, others are not really "supported" yet but if you want to add scripts for different version go check [the contributing rules and application](CONTRIBUTING.md).
